# Перевірка безкоштовного розгортання

17.11.2026. Локально підготовлено Render Free + зовнішній PostgreSQL Supabase Free; альтернативно той самий API можна запускати в Google Cloud Run із billing-акаунтом. Жодних хмарних ресурсів у цьому запуску не створено.

- 48 API-тестів пройшли на SQLite для development-сумісності.
- 48 API-тестів пройшли на справжньому тимчасовому PostgreSQL у режимі зберігання ZIP у базі: [журнал](postgres-tests.log).
- Перевірені збереження ZIP після перезапуску з порожнім локальним диском, приватний доступ, оновлення/видалення старої копії, конфлікти, відкат помилки запису та відмови для великих/некоректних архівів.
- `render.yaml` перевірений за офіційною схемою Render: `plan: free`, без платного диска й Render Postgres.
- Перевірка складу серверного архіву пройшла. Секрети та дослідницькі дані не включені.

PostgreSQL-таблиці мають RLS без browser-політик. API використовує серверного привілейованого користувача; клієнтський Supabase Data API не призначений для доступу до цих таблиць.

ZIP обмежений 20 МіБ; усі ZIP займають спільну квоту PostgreSQL. Supabase Free наразі має квоту БД 500 МБ і може призупиняти неактивні проєкти. Render Free засинає після простою. Реальні квоти, тарифи та умови слід перевірити при створенні акаунтів. Production-підключення Supabase та Google OAuth на новому домені ще не перевірялися.

Інструкція: [FREE_HOSTING.md](../../FREE_HOSTING.md). Зміни ще не опубліковано в GitHub: вибір Render або Cloud Run уточнюється.
