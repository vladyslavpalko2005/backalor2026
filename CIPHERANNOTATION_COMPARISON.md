# Адаптація CipherAnnotation до Backalor

Перевірено 20 жовтня 2026 року: [jurajglatz/CipherAnnotation](https://github.com/jurajglatz/CipherAnnotation), commit `8c026cc1bc2102a640ca3b125e84676698490c41`. Проаналізовано моделі даних, компоненти анотації, каталог символів, експорт, авторизацію й Docker-конфігурацію. Застосунок-референс не запускався; висновки про нього зроблено зі статичного аналізу коду.

Вебверсія має React/TypeScript frontend, ASP.NET API й PostgreSQL. Backalor залишається PyQt6 редактором із локальними JSON та додатковим FastAPI/SQLite бекендом. Функції нижче реалізовано окремо на Python з урахуванням наявного формату даних і навчального каскаду.

## Порівняння

| Рішення у вебпроєкті | Адаптація в Backalor |
|---|---|
| Рекурсивне дерево анотацій | Єдине дерево L1 → L2 → L3 з пошуком, вибором рамки та збереженням розкритих гілок |
| Документні `Caption` | Властивість **Група / підпис** на кожній рамці; пошук у дереві та пакетне призначення |
| Множинний вибір і зміна типу/групи | Cmd/Ctrl/Shift у таблиці оцифрування; пакетна зміна ролі, типу, групи й коду поточної сторінки |
| Дублювання гілки | Копія рамки з нащадками, нові ID, перенесені координати й переприв'язані внутрішні посилання |
| Канонічний `Symbol` і його входження | Каталог кодів символів із назвою, примітками, кількістю входжень та еталонним вирізаним фрагментом |
| Огляд входжень на різних сторінках | Список входжень вибраного коду, перегляд фрагмента й перехід до вихідної анотації |
| `TranscriptionRefId` | Явне посилання шифросимволу на читабельний відкритий текст у тій самій парі L2 |
| Автоматичне заповнення символів | Наявна маршрутизація до локального класифікатора символів та TrOCR, ручна перевірка результатів |
| Облікові записи й документи | Наявний Google-вхід і приватні серверні копії проєктів |
| Експорт навчальних даних | Каскадні YOLO-набори, COCO, фрагменти класифікації та ключ JSON/CSV |

Основні джерела: [Annotation](https://github.com/jurajglatz/CipherAnnotation/blob/8c026cc1bc2102a640ca3b125e84676698490c41/CipherAnnotation/backend/CipherAnnotation.Core/Entities/Annotation.cs), [AnnotationTreePanel](https://github.com/jurajglatz/CipherAnnotation/blob/8c026cc1bc2102a640ca3b125e84676698490c41/CipherAnnotation/frontend/src/components/annotation/AnnotationTreePanel.tsx), [MultiSelectPropertiesPanel](https://github.com/jurajglatz/CipherAnnotation/blob/8c026cc1bc2102a640ca3b125e84676698490c41/CipherAnnotation/frontend/src/components/annotation/MultiSelectPropertiesPanel.tsx), [SymbolCaptionPage](https://github.com/jurajglatz/CipherAnnotation/blob/8c026cc1bc2102a640ca3b125e84676698490c41/CipherAnnotation/frontend/src/pages/SymbolCaptionPage.tsx).

Ієрархія вебпроєкту допускає довільну глибину. У Backalor залишено L1/L2/L3: навчання й детекція використовують конкретну геометрію цих трьох рівнів. Група/підпис — довільна назва, яка не змінює геометричного рівня.

## Як користуватися

### Дерево і групи

У **Розмітка** показано одне дерево. Натискання вибирає відповідну рамку. Пошук за підписом, транскрипцією, кодом або приміткою залишає видимими її предків.

У **Додаткові властивості → Група / підпис** можна ввести назву, наприклад `Alphabet`, `Names`, `Numerals`. Внутрішні старі мітки `symbol` і `not_symbol` зарезервовані для сумісності.

**Дублювати гілку** копіює вибрану рамку й нащадків зі зміщенням на 12 пікселів. Якщо копія виходить за межі зображення чи батька, операція відхиляється без змін. Внутрішні посилання символів на текст перенаправляються на нові ID. Копії потребують перевірки. Undo скасовує всю операцію.

### Пакетне редагування

У **Перевірка** вибери кілька L3 через Cmd/Ctrl або Shift, натисни **Змінити вибрані…**, познач потрібні властивості та задай значення. Непозначені поля залишаться без змін. Операція стосується поточної сторінки й скасовується однією дією Undo.

Зміна ролі, типу чи коду скидає відповідне підтвердження перевірки. Підпис сам по собі не змінює семантику елемента.

### Каталог символів

Відкрий **Символи → Каталог символів**. Каталог групує L3 типу `cipher_symbol` за точним кодом у межах поточного проєкту. Рядок **Без коду** допомагає знайти незавершену розмітку.

Вибери код, потім його входження. Показаний фрагмент завантажується окремо; індексація й перегляд працюють у фонових задачах. **Відкрити анотацію** переводить до потрібного скану й рамки.

**Додати / змінити опис…** зберігає назву та примітки для коду. **Зробити еталонним** позначає вибране входження як приклад для цього коду. Еталон — посилання на вирізку, а не окрема намальована картинка. Якщо вихідну рамку прибрано або перекодовано, каталог повідомить про недоступний еталон.

Видалення опису з каталогу зберігає анотації й їхні коди. Щоб перенести входження до іншого коду, зміни код у властивостях або пакетно на відповідній сторінці. Перейменування коду на всіх сторінках однією транзакцією не реалізовано.

### Явний зв'язок із текстом

Для L3 типу **Шифросимвол** у властивостях вибери **Пов’язаний відкритий текст**. Список містить читабельні L3 з роллю відкритого тексту під тим самим L2. Посилання необов'язкове: без нього ключ зберігає відповідність на рівні всієї пари.

Перевірка знаходить посилання на відсутню рамку, на себе, іншу пару, неправильний тип або роль. Такі дані можна зберегти як чернетку, але ключ не отримає статус `ready`. Зміна транскрипції цільового тексту скидає підтвердження пов'язаного символу.

JSON ключа містить `transcription_ref_id`, розв'язану `linked_transcription` і каталог визначень символів. У COCO є локальний ID та окремий `transcription_ref_annotation_id`, перерахований до глобального ID експорту. CSV зберігає посилання всередині JSON-полів елементів; описи каталогу доступні в JSON ключа й ZIP проєкту.

## Дані та сумісність

Анотації тепер використовують `schema_version: 4`. Файли версій 1–3 читаються; відкриття не переписує їх. Нове збереження використовує версію 4 і зберігає попередню версію в `.json.bak`.

Каталог міститься в `project.json → symbol_catalog`. Зміна каталогу зберігає інші метадані та резервну копію `project.json.bak`. Поточні ZIP та серверні копії переносять і каталог, і явні посилання. Старі версії редактора не повинні редагувати новий формат.

COCO референсного проєкту експортує категорію та геометрію, але не всі внутрішні зв'язки, описи символів і довільну вкладеність. Автоматичне відновлення його повного робочого стану з такого COCO не реалізовано. Деталі: [ExportService](https://github.com/jurajglatz/CipherAnnotation/blob/8c026cc1bc2102a640ca3b125e84676698490c41/CipherAnnotation/backend/CipherAnnotation.Infrastructure/Services/Export/ExportService.cs).

## Межі адаптації

Окреме малювання еталонного символу, поворот рамок, блокування гілок, довільна глибина дерева, публічні документи, запрошення співавторів, ролі адміністратора та сповіщення вебпроєкту в цій адаптації не реалізовані. Серверна модель Backalor залишається приватною копією проєкту з ручним передаванням змін. Навчені ML-моделі не завантажувалися й не навчалися під час цієї роботи.
